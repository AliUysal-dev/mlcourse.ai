# Assignment 1: Exploratory Data Analysis with Pandas

This directory contains the code and solutions for Assignment 1 of the mlcourse.ai program, focusing on exploratory data analysis using the Adult Census Income dataset.

## Contents

- [Jupyter Notebook Solution](assignment_1.ipynb)

## Key Topics & Questions Covered

1. Demographic distribution analysis (gender representation)
2. Statistical age computations across different gender and salary groups
3. Percentage calculations for specific nationalities
4. Conditional filtering and data aggregations using pandas functions
5. Impact of marital status and work hours on income levels

## Dataset

- **Dataset:** Adult Census Income (`adult.data.csv`)
- **Primary Library:** Pandas
