# Assignment 2: Exploratory Data Analysis of Cardiovascular Disease Data

This directory contains the code and solutions for Assignment 2 of the mlcourse.ai program, focusing on exploratory data analysis and data visualization using the Cardiovascular Disease dataset.

## Contents

* [Jupyter Notebook Solution](assignment-2.ipynb)

## Key Topics & Questions Covered

1. Data cleaning and filtering (removing anomalies in blood pressure, height, and weight based on percentile thresholds)
2. Feature engineering (calculating age in years and Body Mass Index - BMI)
3. Correlation analysis using both Pearson linear correlation and Spearman's rank correlation coefficients
4. Visual data analysis with heatmaps (`sns.heatmap`), violin plots (`sns.violinplot`), and count plots (`sns.countplot`)
5. Exploring the relationship between age, physiological parameters, and cardiovascular disease prevalence
