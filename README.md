## Kaggle Competitions

* **Assignment 6 — Catch Me If You Can (Alice):** session-based user identification with severe class imbalance. Final score: **0.93048** (private ROC-AUC).
* **Assignment 10 — Flight Delays:** predicting flight departure delays with XGBoost + Logistic Regression blending. Final score: **0.71755** (ROC-AUC), beating the first competition benchmark.
